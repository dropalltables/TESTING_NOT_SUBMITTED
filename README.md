# tidepool

Small tide table CLI.

## Usage

```
uv run tidepool --station 9414290
```

## Data

Station ids follow the NOAA CO-OPS numbering.

## Notes

Station ids follow the NOAA CO-OPS numbering.

## Notes

Readings are stored as JSON per station under `tidepool/data`.

## Stations

Readings are stored as JSON per station under `tidepool/data`.
